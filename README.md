# Mi portfolio de desarrollador. Pablo Gamo González

Portfolio personal de Pablo Gamo, desarrollado con [Astro](https://astro.build/).

El proyecto recoge mi experiencia profesional como Ingeniero de Software, mis principales tecnologías, formación y proyectos personales.

## Características

- Diseño responsive adaptado a escritorio, tablet y móvil.
- Soporte para modo claro, oscuro y según preferencias del sistema.
- Internacionalización (Español / Inglés).
- Navegación por secciones con scroll suave.
- Apartados de experiencia profesional, tecnologías, educación y proyectos.
- Información sobre experiencia en desarrollo de software e IA aplicada.
- Animaciones e interacciones sutiles para mejorar la experiencia de usuario.

## Tecnologías

- **Astro**
- **Tailwind CSS**
- **JavaScript / JSX**
- **HTML / CSS**
- **React** para componentes interactivos
